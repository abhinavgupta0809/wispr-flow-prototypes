Mobile Fix Strip

Mobile users can enjoy Flow's dictation quality but lose the time-saving benefit when correcting a phrase requires awkward selection, typing, or switching keyboards.

2 · What Flow ships today

Flow already edits by voice on desktop. On iPhone, in-place editing isn't currently working

This proposal is about one mobile interaction, not voice editing in general.

3 · The proposed change

Correct a selected phrase, keep everything around it

Proposed
  • Opt-in, not a gate. A small Fix control appears after a dictation. Nothing opens unless you tap it; there's no review screen after every dictation.
  • Only the latest dictation. The strip shows that text as tappable words, so you never place a cursor in a long field.
  • Tap a word, or two to make a phrase. Then say the replacement, or type it.
  • See it before it lands. The phrase is shown changing in place. Apply, cancel, or undo afterwards.
  • Exact replacement. Only the selected characters change. No rewrite of the rest of the message.

    6 · Scope boundary

    What this prototype does not show

    • It does not work in other iOS apps. A real keyboard extension would need a native check: can it reliably find the last dictated text in the host app's field, and replace that exact range safely, with the cursor moved by the user or by autocorrect?
    • It does not recognize speech. Replacement by voice uses a prepared phrase.
    • It handles one replacement and one level of undo.
    • It has not been tested with users.
