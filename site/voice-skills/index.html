Voice Skills

When the work is a routine.

Flow spots a routine you repeat. Save it once, then run it with one voice command.

Problem

A PM rebuilds the same morning brief from Gmail, Slack and Excel, by hand, every day.

Hypothesis Flow saves repeated text (Snippets), not repeated work. No review asks for this yet.

Solution

Flow spots the routine. You save it once, then say /morning.

      Rules it followsDiscovery, saving, running
      • Suggests a skill after three completed runs of the same routine. Retries and cancelled runs don't count.
      • Learns only from tasks run through Flow. It doesn't watch other apps.
      • Asks only what it can't infer. Nothing is saved until you say so.
      • Only a command at the very start of a dictation runs a skill. Unknown commands never guess.
      • If one tool fails, the rest is kept and only that step retries. Nothing posts twice.
      What this prototype doesn't showLimits
      • No real connections or speech recognition. Every email, message and number is sample data.
      • No real discovery. How Flow would recognize "the same routine" is an open design and privacy question.
      • Briefs are built by fixed rules, not a model. Not yet tested with users.
